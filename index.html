THE RECURSION PLAYGROUND

Tower of Hanoi

Move every disk from A to C. Larger disks cannot sit on smaller ones.

Moves: 0

Minimum: 31

Select a tower, then select a destination.

How recursion solves it

  1. Move the top n − 1 disks to the spare tower.
  2. Move the largest disk to the destination.
  3. Move the n − 1 disks onto the largest disk.
def solve(n, src, dst, via):
    if n == 0:
        return

    solve(n - 1, src, via, dst)
    move(src, dst)
    solve(n - 1, via, dst, src)

The minimum number of moves is 2ⁿ − 1.
